# 塔罗牌占卜微信小程序需求文档

## 1. 应用概述

### 1.1 应用名称
塔罗之光

### 1.2 应用描述
一款面向初学者的塔罗牌占卜微信小程序，基于莱德韦特体系开发，兼顾易用性与专业性，为用户提供沉浸式的占卜体验与实用的解读指导。\n
## 2. 核心功能

### 2.1 牌库系统
- 采用标准78张韦特塔罗牌结构
- 包含22张大阿卡纳牌和56张小阿卡纳牌
- 小阿卡纳牌组分类：\n  - 权杖牌组（火元素）：行动与创造主题
  - 圣杯牌组（水元素）：人际与情感主题
  - 宝剑牌组（风元素）：伤害与思考主题
  - 星币牌组（土元素）：物质与享受主题

### 2.2 占卜功能

#### 2.2.1 牌阵选择
- 基础单张牌解读（是否类问题快速占卜）\n- 经典三张牌阵（过去-现在-未来时间流分析）\n- 综合凯尔特十字牌阵（深度问题全面解析）\n- 生活场景专题牌阵（8个主题）：\n  a. 爱情与亲密关系专题
  b. 职业发展与事业规划专题
  c. 财务状况与投资决策专题
  d. 学业考试与知识提升专题
  e. 个人成长与灵性探索专题
  f. 身心健康与情绪管理专题
  g. 家庭关系与人际交往专题
  h. 重大决策与人生方向专题

#### 2.2.2 抽牌模式
- 支持用户自定义问题输入
- 支持随机抽牌模式
- 支持手势滑动选择正逆位

### 2.3 交互体验

#### 2.3.1 洗牌动画
- 点击洗牌按钮后牌背动态翻转，模拟实体牌洗牌过程

#### 2.3.2 引导语提示
- 关键步骤显示引导语：\n  - 请深呼吸集中意念
  - 默念您的问题感受牌面能量

#### 2.3.2 牌面展示
- 高清牌面图像展示
- 标准中文牌名标注
- 正逆位状态标识
- 核心关键词提示
- 分层解读内容（基础含义+情境建议）\n
### 2.4 内容体系

#### 2.4.1 牌义数据库
- 构建完整的牌义数据库
- 包含正逆位差异化解读
- 采用温和中立的表达方式
- 强调：\n  - 占卜结果作为可能性参考
  - 鼓励用户自主思考与选择
  - 避免绝对化表述和负面暗示
- 解读框架包含：\n  - 牌面象征意义解析
  - 对应生活场景提示
  - 实践行动建议指导

### 2.5 用户数据管理

#### 2.5.1 占卜记录
- 自动生成占卜记录档案
- 记录内容：\n  - 占卜时间戳
  - 用户提问内容
  - 使用牌阵类型
  - 抽牌结果详情

#### 2.5.2 分享功能
- 设计可分享的视觉卡片模板
- 包含：\n  - 精选牌面组合排版
  - 个性化解读摘要
  - 小程序二维码入口

### 2.6 视觉设计

#### 2.6.1 色彩方案
- 主色调：深紫色（神秘感）+墨绿色（平和感）+金色（点睛色）\n
#### 2.6.2 动态效果
- 柔和光晕过渡
- 微细粒子浮动动画

#### 2.6.3 版式设计
- 留白充足的信息层级布局

#### 2.6.4 图像资源
- 使用公版韦特塔罗牌扫描素材

### 2.7 法律合规

#### 2.7.1 免责声明
- 首页底部固定显示：本程序仅供娱乐与自我探索，不替代专业建议"\n- 结果页增加提示语：塔罗牌是映照内心的工具，真正的力量源于您的选择"\n
## 3. 界面交互流程

### 3.1 首页
- 展示牌阵分类入口
- 显示快速抽牌按钮
- 显示占卜记录入口

### 3.2 牌阵选择页
- 展示多维度牌阵分类
- 用户选择牌阵类型

### 3.3 问题输入页
- 用户输入自定义问题
- 或直接进入随机抽牌模式

### 3.4 洗牌动画页
- 播放拟真洗牌动画
- 显示引导语提示

### 3.5 抽牌结果页
- 展示抽牌结果
- 显示牌面图像与解读内容
- 提供分享功能

### 3.6 占卜记录页
- 展示历史占卜记录
- 支持查看详细记录
- 支持分享历史记录
